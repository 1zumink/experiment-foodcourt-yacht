# Эксперимент: фудкорт и яхта (прототипы)

`http://localhost:5173/` — стартовая страница со ссылками на обе части.

Опубликовано на GitHub Pages: https://1zumink.github.io/experiment-foodcourt-yacht/ (собирается автоматически при пуше в `main`, `.github/workflows/pages.yml`).

# Часть 1. Фудкорт — единая касса

Единый терминал самообслуживания для 8 ресторанов фудкорта + ТВ-табло выдачи.
Первый экран повторяет макет Figma (карта фудкорта 1080×1920).

```bash
npm install
npm run dev
```

- `http://localhost:5173/#/kiosk` — терминал (портрет 1080×1920, вписывается в окно)
- `http://localhost:5173/#/display` — табло выдачи (1920×1080). Откройте во второй вкладке: заказы с терминала появляются там сразу (localStorage + BroadcastChannel).
- `http://localhost:5173/#/app?table=14` — приложение для заказа за столом (так выглядит ссылка из QR-кода на столе 14). Без `table` приложение попросит отсканировать QR или ввести номер стола. На телефоне открывается на весь экран, на компьютере — в рамке телефона.

## Приложение (заказ за столом)
Стол из QR → рестораны → меню (табы прокручивают к разделу) → блюдо (те же добавки и комбо, что в киоске, общий хук `useItemConfig`) →
корзина из разных ресторанов, бонусы по телефону, оплата (мок) → отслеживание: по карточке на ресторан, шаги «Принят → Готовится → Несём к столу → На столе».
Заказы всегда с доставкой к столу и сразу видны на табло («→ стол 14»). Мои заказы хранятся на устройстве, можно дозаказать — прошлые уйдут в «Ранее».

## Флоу
Карта → меню ресторана → карточка блюда (добавки, обязательные опции, комбо) → общая корзина из разных ресторанов →
получение (сам / к столу с выбором стола на карте) → бонусы (один телефон на все программы; баллы или штампы) →
оплата (карта / СБП, мок) → коды выдачи (свой код от каждого ресторана, префикс + номер).

Время готовки ускорено для демо (20–40 с). На табло клик по коду переключает статус, «Демо-заказы» заполняют табло.

## Доступность
Кнопка «Доступность» всегда внизу: крупный текст, высокий контраст, «интерфейс ниже» (для невысоких людей и на коляске), English.
Таймер бездействия сбрасывает брошенный заказ.

## Где что
- `src/data/restaurants.ts` — рестораны, цвета, логотипы (кадрирование из Figma), программы лояльности
- `src/data/menus/*` — меню
- `src/data/floor.ts` — геометрия карты из Figma
- `src/screens/kiosk/*` — экраны терминала, `src/screens/display/PickupBoard.tsx` — табло
- `src/app/*` — мобильное приложение, стили в `src/styles/mobile.css`

# Часть 2. Яхта — пульт владельца

- `#/yacht?d=phone` — телефон в рамке (на телефоне — во весь экран)
- `#/yacht?d=tablet` — планшет в рамке
- `#/yacht` — во всё окно, раскладка подстраивается под размер

Не пульт экипажа, а игрушка владельца: в центре — изометрическая 3D-яхта в разрезе на «диораме» моря (three.js + react-three-fiber), и каждое действие видно на ней:
- **Ход** — машинный телеграф (Стоп / Малый / Средний / Полный) и штурвал; растёт кильватерный след, вода бежит мимо, яхта рыскает и кренится в повороте, компас по краю моря поворачивается, латунная метка показывает заданный курс.
- **Музыка** — колонки в выбранных зонах пульсируют, из них летят ноты; свет дышит в такт.
- **Свет** — сцены День / Закат / Вечеринка / Ночь меняют небо, воду, лампы и тему интерфейса (ночью — тёмно-синий с латунью); подводная подсветка.
- **Джакузи** — круговой регулятор 30–40 °C, вода теплеет по цвету, идёт пар.
- **Сервис** — блюда и напитки, место подачи можно выбрать прямо на яхте; стюард с клошем идёт из камбуза.
- **Капитан** — удержание кнопки передаёт управление (навигация блокируется, комфорт остаётся), вернуть — запросом.
- **Шторм** — кнопка «Вызвать шторм» рядом с рамкой (или долгое нажатие на название яхты): волны, дождь, молнии и одна большая кнопка «Передать капитану» с автопередачей через 10 с.

Где что: `src/yacht/state.ts` — состояние и симуляция, `src/yacht/scene/*` — 3D, `src/yacht/ui/*` — панели, стили — `src/styles/yacht.css`.

## Экспорт яхты в Figma (dev)
Страница «Яхта» в Figma: секции День / Закат / Вечеринка / Ночь (по 8 экранов на телефон 390×844 и планшет 1180×820) и Шторм. Всё редактируемое, 3D-сцена — картинкой.

1. `npm run dev`, открыть `#/yacht` в окне 390×844 и в консоли `await __yShots('phone')`, затем в окне 1180×820 — `await __yShots('tablet')`. Слепки слоёв (JSON) и PNG сцены сохраняются в `.figma-captures/`.
2. `node scripts/figma/bundle.mjs` — упаковывает слепки и сборщик в PNG-контейнеры (`.figma-captures/out/manifest.json`).
3. Загрузить файлы манифеста через `upload_assets` на прямоугольники-приёмники (`node scripts/figma/upload.mjs <manifest> <urls.txt>`), затем в `use_figma` прочитать сборщик `scripts/figma/builder.js` из контейнера и вызвать `build()` для каждой группы.
